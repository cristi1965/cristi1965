## 正在构建

我关注的不只是“代码能跑”，而是知识能不能被理解、练习能不能被验证、系统能不能在真实边界下稳定运行。

- **Go 与后端工程**：从语法、数据库到并发与工程化实践。
- **AI Agent 工程**：工具调用、状态管理、审批、恢复与可验证执行。
- **交互式学习**：把教程做成可操作、可反馈、可积累的学习系统。
